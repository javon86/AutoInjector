🧙 Setup Wizard

Sign in to ChatGPT, Claude and Gemini in their panes. Here you can also set up a local AI (for 🎩 Alfred), pictures, video and voice — all optional.

A local AI runs a language model on your own computer — it is what 🎩 Alfred thinks with. Pick a runtime, then download a model.

Runtime:

Pictures are set up in the 🎨 Images tab of the main window. It finds Forge / A1111 / ComfyUI for you (and tells you if --api is missing), can start Stability Matrix packages or install ComfyUI (⚙ Start & install), has the LoRA library and character locks, and — under Advanced: another server — lets you point at a Stable Diffusion app on another computer.

Videos are set up in the 🎬 Video tab of the main window. Under ⚙ Setup & models one click installs ComfyUI and a Wan video model; Advanced: other video server connects a separate text-to-video server (AnimateDiff, Stable Video Diffusion) with its own clip settings.

Let the app install the extras for you — no commands to type. Auto-setup installs Open Interpreter (so the butler can run code), the offline voice engine + a voice, and a small local model, then opens the picture-making installer. Or install one piece at a time below.
