A local AI runs a language model on your own machine — used by the optional System AI helper. Pick a runtime, then add the models you want.

Image generation runs on a local Stable Diffusion server (a GPU app you run yourself). The butler's GENERATE_IMAGE renders into it. Install one from the Installs tab, launch it with its API on, then point the app at it here.
