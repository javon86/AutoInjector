# Writing Tool Prompts (W1–W15)

Prompts that improve ChatGPT/Claude writing **without changing the program**.
Paste a prompt into any AI; it builds the tool as a reusable instruction
(ChatGPT Custom GPT, Claude Project instruction, or start-of-chat paste).

**Suggested order:** while writing → W1, W6, W7 · cleanup → W2, W3, W4, W13, W14 ·
review → W5, W8, W9, W15 · first/last paragraphs → W10, W11 · whole book → W12.

---

## W1. Voice Lock — keeps each character sounding like themselves
```
Write me a reusable AI instruction called "Voice Lock." Before writing any scene, the AI must list each speaking character's vocabulary level, sentence length, verbal habits, and things they would never say, then write the dialogue so that any line could be identified by speaker with the name tags removed. After writing, it checks each line against the list and rewrites any line that could belong to someone else.
```

## W2. Cliché Hunter — finds and replaces stock phrases
```
Write me a reusable AI instruction called "Cliché Hunter." The AI scans a chapter for stock phrases, overused AI-isms (e.g. "a testament to," "the weight of," "something shifted," "breath she didn't know she was holding"), and dead metaphors. It lists each one with its line, then gives a replacement that is specific to this story's world and characters, never a different cliché.
```

## W3. Repetition Sweeper — catches repeated words, images and beats
```
Write me a reusable AI instruction called "Repetition Sweeper." The AI finds repeated words within 200 words of each other, repeated images or gestures across the chapter (e.g. characters nodding, jaws tightening, light catching things), and repeated emotional beats. It reports them in a table ranked by how noticeable they are, then fixes the top ones.
```

## W4. Show-Don't-Tell Converter — turns stated emotions into action
```
Write me a reusable AI instruction called "Show-Don't-Tell Converter." The AI finds sentences that name an emotion or trait outright ("she was angry," "he felt guilty," "it was clear that"). It rewrites each one as action, dialogue, body language or a choice the character makes, keeping the original only where telling is actually faster and better.
```

## W5. Harsh Editor — an honest critic that doesn't hand out 10/10s
```
Write me a reusable AI instruction called "Harsh Editor." The AI acts as a demanding fiction editor at a major publisher. It may not give any score above 7/10 unless it can quote three specific passages that prove it. It must list at least five concrete weaknesses with line quotes before saying anything positive, and it ends with the single change that would most improve the chapter.
```

## W6. Sensory Anchor — grounds scenes in the physical world
```
Write me a reusable AI instruction called "Sensory Anchor." For each scene the AI checks that the reader knows where they are within the first 3 sentences and that at least three senses are used across the scene. It adds one specific, unexpected physical detail per scene that only this setting could have. It never adds weather or light descriptions just to fill space.
```

## W7. Subtext Coach — stops characters from saying exactly what they mean
```
Write me a reusable AI instruction called "Subtext Coach." The AI finds dialogue where characters state their feelings or motives directly. It rewrites the dialogue so the real meaning is underneath: characters dodge, deflect, argue about something smaller, or say the opposite. Each rewrite gets a one-line note of what is actually being said.
```

## W8. Pacing Map — shows where the chapter drags or rushes
```
Write me a reusable AI instruction called "Pacing Map." The AI breaks a chapter into beats and labels each one as action, dialogue, reflection, description or transition, with its word count. It flags any stretch over 400 words without a change or new tension, and any important moment that was rushed in under 100 words. It then suggests specific cuts and expansions.
```

## W9. Scene Purpose Test — makes sure every scene earns its place
```
Write me a reusable AI instruction called "Scene Purpose Test." For each scene the AI answers: What does the character want here? What stops them? What changes by the end? What would be lost if this scene were cut? Any scene with no change or nothing lost gets flagged, with options to merge it, cut it or raise its stakes.
```

## W10. Opening Hook Doctor — strengthens chapter openings
```
Write me a reusable AI instruction called "Opening Hook Doctor." The AI reviews a chapter's first paragraph and writes 5 alternative openings, each using a different technique: mid-action, striking line of dialogue, odd detail, a question raised, a contradiction. It rates each one for pull and explains which fits the chapter best.
```

## W11. Chapter Ending Doctor — makes readers turn the page
```
Write me a reusable AI instruction called "Chapter Ending Doctor." The AI checks whether a chapter ends on a summary, a character going to sleep, or a tidy resolution. It writes 3 alternative endings that close on an open question, a reveal, a decision or a shift in power, without cheap fake-out cliffhangers.
```

## W12. Continuity Checker — catches mistakes between chapters
```
Write me a reusable AI instruction called "Continuity Checker." Given a story bible and chapters, the AI tracks names, ages, eye/hair colors, injuries, objects held, locations, time of day, and who knows which secrets. It lists every contradiction with the chapter and line where it appears, and suggests the smallest fix.
```

## W13. Prose Rhythm Tuner — varies sentence length and flow
```
Write me a reusable AI instruction called "Prose Rhythm Tuner." The AI measures sentence lengths in a passage and flags runs of 4+ sentences with similar length or the same opening structure (e.g. "She…She…She…", or starting with -ing phrases). It rewrites those runs for varied rhythm, using short sentences for impact and longer ones for flow, without changing meaning.
```

## W14. Specificity Upgrader — replaces vague words with concrete ones
```
Write me a reusable AI instruction called "Specificity Upgrader." The AI finds vague nouns, verbs and modifiers ("thing," "something," "walked," "very," "really," "somehow," "a sense of"). It replaces each with the precise, concrete word this character in this world would use. Each change gets a short reason, and it never adds more adjectives.
```

## W15. Reader Reaction Simulator — shows how a real reader would feel
```
Write me a reusable AI instruction called "Reader Reaction Simulator." The AI reads a chapter as three different readers (a genre fan, a casual reader and a critical literary reader) and notes, paragraph by paragraph, where each would be hooked, bored, confused or moved. It ends with the top 3 moments to cut, the top 3 to strengthen, and any place a reader would stop reading.
```
