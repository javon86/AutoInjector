- **Likely cause:** `try_backup` is best effort and returns None on any error; `_s_backup` only writes the step line “Backup could not be written (continuing; see Health)” and carries on. No journal code, no warning on the finished run, nothing in “Needs a look”; only the separate ❤️ Health page turns amber (“The last automatic backup failed”).
